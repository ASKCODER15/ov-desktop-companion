# Support

For setup questions, usage questions, and reproducible bugs:

1. Read the setup and troubleshooting sections in `README.md`.
2. Search the GitHub issues for an existing answer.
3. Open a GitHub issue with the relevant template and sanitised diagnostic details.

For suspected security vulnerabilities, do not open a public issue. Follow `SECURITY.md`.

OV is currently documented as a Windows desktop application. Issues caused by unsupported operating systems or unlisted third-party tools may not be reproducible by maintainers.
